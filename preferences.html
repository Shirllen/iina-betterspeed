Uses mpv key binding format, for example: z, Shift+z, Ctrl+z. Changes are applied to the Plugin menu within about one second.

Used when there is no remembered non-1.0x speed yet. Default: 2.0.

BetterSpeed is primarily designed to mimic YouTube-style SPACE behavior: a quick tap pauses or resumes when the key is SPACE, while a brief hold switches to the temporary speed until you release it. Important: IINA sends menu shortcuts to itself before plugins can inspect them. To make default SPACE tap/hold work, first remove or remap IINA's own SPACE shortcut in Key Bindings. Uses mpv key binding format, for example: SPACE, Shift+SPACE, Ctrl+SPACE. Avoid choosing keys that are still bound to IINA commands, or whose normal long-press repeat you want to keep, such as seek keys. Leave it empty to disable this feature.

Default: 2.0. BetterSpeed keeps SPACE tap-to-pause behavior internally after you unbind IINA's own SPACE shortcut, and only hijacks the key when you hold it briefly.

BetterSpeed started as a PotPlayer-style Z-key speed toggle for IINA. The toggle shortcut is still registered through the Plugin menu, and IINA does not currently expose plugin-defined actions in the built-in Key Bindings action list.

Uses mpv key binding format, for example: z, Shift+z, Ctrl+z. Changes are applied to the Plugin menu within about one second.

Used when there is no remembered non-1.0x speed yet. Default: 2.0.

BetterSpeed is primarily designed to mimic YouTube-style SPACE behavior: a quick tap replays the key's normal IINA or mpv action, while a brief hold switches to the temporary speed until you release it. With the default SPACE key, that usually means tap to pause or resume, hold to speed up. Uses mpv key binding format, for example: SPACE, Shift+SPACE, Ctrl+SPACE. Avoid choosing keys whose normal long-press repeat you want to keep, such as seek keys. Leave it empty to disable this feature.

Default: 2.0. BetterSpeed forwards quick taps to the configured key's original binding and only hijacks the key when you hold it briefly.

BetterSpeed started as a PotPlayer-style Z-key speed toggle for IINA. The toggle shortcut is still registered through the Plugin menu, and IINA does not currently expose plugin-defined actions in the built-in Key Bindings action list.
